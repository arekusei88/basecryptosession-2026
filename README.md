# Сессионное задание по дисциплине «Основы криптографии»

НИЯУ МИФИ, Институт интеллектуальных кибернетических систем, группа
М26-545, 2026 год.

Отчёт: [session_assignment_report.pdf](session_assignment_report.pdf).

В отчёте — ответы на шесть вопросов итогового задания:

1. Трёхсторонний протокол распределения ключей между парами участников с
   использованием третьей стороны.
2. Формальные модели шифров.
3. Принципы построения поточных систем шифрования.
4. Режим шифрования, в котором биективность шифрующих отображений базового
   режима не нужна для однозначного расшифрования.
5. Число искажённых 64-битовых блоков открытого текста при ошибке в одном
   бите шифртекста в режиме гаммирования с обратной связью по шифртексту с
   8-битовыми блоками.
6. Размерность значения хэш-функции, при которой случайная пара сообщений
   составляет коллизию с вероятностью не больше 10⁻⁹.
